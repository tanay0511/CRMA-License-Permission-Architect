1. Security Predicates Bypass with "Manage CRM Analytics"

If a user has Manage CRM Analytics or Salesforce's global View All Data, dataset row-level security predicates are completely bypassed. Never assign Manage CRM Analytics to dashboard designers or business managers who should only see their own department's data.

2. Cross-App Dataset Dependency

A user can have Editor access to "Dashboard App A", but if the dashboard queries a dataset residing in "Core Data App B", the user must have at least Viewer access to App B. Otherwise, widgets querying that dataset will fail with access errors.

3. CSV Export: Two Keys Needed

For a user to download CSV data, two criteria must be satisfied: (a) User must possess the Download CRM Analytics Data system permission, and (b) The specific dashboard widget must not have its action menu disabled in dashboard properties.

4. Growth vs. Plus Pricing Discrepancy

CRM Analytics Plus costs significantly more than Growth. Only assign Plus to users requiring Einstein Discovery automated story creation, model deployment, or live predictions in core workflows. Standard dashboards and recipes run identically under Growth.
